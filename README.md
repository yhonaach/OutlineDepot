# OutlineDepot

OutlineDepot is a data-driven knowledge management system featuring auto-layout and version-control capabilities in a dynamic studio environment.

With OutlineDepot, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/OutlineDepot.git`
2. `cd OutlineDepot`
3. Install in editable mode: `pip install -e .`

## Configuration

OutlineDepot is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
